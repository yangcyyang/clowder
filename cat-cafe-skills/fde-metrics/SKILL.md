# FDE 四层指标体系

## R — 原文 (Reading)

> "指标贵精不贵多——每个客户项目盯住 3 到 5 个核心指标，胜过铺满一面墙的仪表盘。……基线数据在项目启动第一天采集——错过永不再来。指标与客户共建、双方共认，否则它在续约谈判桌上没有效力。"
>
> — 范冰《前线部署工程师》附录 A

---

## I — 方法论骨架 (Interpretation)

四层指标体系覆盖 FDE 工作全链路，判断"项目做得对不对 / 客户活得怎么样 / 生意值不值 / 团队能不能走远"：

**交付层（项目做得对不对）**
- TTV（Time to Value，价值实现时间）：进场到第一次可衡量价值的时间；生命线指标（MVD 以周计 2-6 周，完整部署以月计 1-4 个月）；持续变长=方法论或平台底座出问题的第一信号
- 概念验证转化率：验证进付费部署比例（训练营从 5-10% 提到约 75%）；过低=筛选失职，过高=只接没挑战的单
- 评估达标率 + 部署频次与回滚率 + 缺陷逃逸率（测测试体系完备性）

**客户层（客户活得怎么样）**
- 激活率：目标用户群中形成稳定使用习惯的比例（分母是目标用户群不是账号数）
- 使用深度：关键功能几成人在用/频次分布/自助探索行为（最珍贵信号）
- 健康度评分：使用/价值/关系/商业四类信号合成；每周全量巡视，跌破警戒线触发干预
- 支持者覆盖数：单点是高危，三点成网
- NPS 慎用：企业场景样本小政治化；更可靠的是"续约意向提前问询"（到期前两季度直接问支持者）

**商业层（生意值不值）**
- NRR：总裁判，及格 100% 优秀 120%（Palantir 139%）
- 交付毛利率：纯人力期 20-40%，平台复用后向 60% 以上；涨得快不快比绝对值更重要——不上升的 FDE 是咨询公司
- 定制递减率：麦格鲁试金石——连续三个客户定制量不降，立即检视产品回流机制
- 销售周期（训练营 9-12 月→数周）+ CAC 回收期 + LTV/CAC（健康线 3 以上，早期可能低于 2 需配 NRR 读）

**组织层（团队能不能走远）**
- 现场到产品回流速率：组件入库/手册更新/平台化提案数——FDE 模式的"灵魂器官"
- 交付资产复用率：目标逐季上升
- FDE 人均产能：平台化后应持续抬升
- 团队续航：出差强度/值班负荷/离职率——团队烧干了前面所有指标都是烟花

使用建议：每客户 3-5 个核心指标组合（价值+使用+关系）/ 基线第一天采集 / 指标与客户共建 / 半年检修指标体系。

## A1 — 书中的应用 (Past Application)

### 案例1: Palantir NRR 139% + 毛利率 82%
- **问题**: 怎么证明"交付即经营"模式成立？
- **方法论的使用**: NRR 139%（不含新签）+ 毛利率 82%
- **结论**: 老客户的信任在增值，服务成本被平台持续摊薄
- **结果**: 成为商业层指标的标杆

### 案例2: 训练营转化率 5-10% → 75%
- **问题**: 怎么衡量客户筛选与交付质量？
- **方法论的使用**: 概念验证转化率同时测量"客户筛选质量"与"交付质量"
- **结论**: 转化率过低=进场筛选失职，过高=只接没挑战的单
- **结果**: 训练营把转化率提升到约 75%

### 案例3: MIT 激活率警戒线
- **问题**: 激活率多少算危险？
- **方法论的使用**: 仅约四成企业为员工提供官方 AI 订阅——激活率长期低迷，部署名义上活着实际上死了
- **结论**: 激活率分母是目标用户群而非账号数
- **结果**: 成为客户层指标的行业基准

## E — 可执行步骤 (Execution)

1. **按项目定 3-5 个核心指标**
   - 完成标准：每个项目选——1 个价值指标（如 TTV/省工时）+ 1 个使用指标（激活率/使用深度）+ 1 个关系指标（健康度/支持者覆盖）
   - 判停条件：指标超过 5 个 → 砍；指标一多就等于没有指标

2. **第一天采集基线**
   - 完成标准：项目启动当天记录改造前数据（处理时长/错误率/工时）
   - 判停条件：项目已开始还没基线 → 立即补（虽不完整，但能补多少补多少）
   - 备注：基线错过永不再来

3. **指标与客户共建**
   - 完成标准：立项会上与客户确认指标定义与测量方法
   - 判停条件：客户不认指标 → 在谈判桌上没有效力，先对齐

4. **建健康度与仪表盘**
   - 完成标准：四类信号（使用/价值/关系/商业）合成健康分，跌破警戒线自动触发干预
   - 判停条件：没有预警机制 → 关系变质只会是突然死亡

5. **季度检视模式健康度**
   - 完成标准：看 NRR（≥120% 优秀）/ 毛利率趋势（上升？）/ 定制递减率（连续 3 客户不降=回流失效）/ 团队续航
   - 判停条件：毛利率不升 → "不上升的 FDE 是咨询公司"；定制不降 → 检视回流机制
   - 备注：半年检修指标体系本身（删除无人看的，补上反复被问的）

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 单点技术性能排查（用 SRE 类工具）
- 财务合规报表（会计准则，非经营分析）

### 书中警告的失败模式

- 指标铺满墙：指标一多就等于没有指标
- 无基线：价值证明永缺一角
- 指标单方面定：客户不认的指标在谈判桌上无效
- 只看 NRR 绝对值：要配合毛利率/定制递减率读
- 忽视团队续航：团队烧干了，前面所有指标都是烟花

### 作者的盲点 / 时代局限

- 指标数值（NRR 120%、毛利率 60%、LTV/CAC 3）基于 2025-2026 样本，行业成熟后会变化
- "概念验证转化率接近 100%=只接没挑战的单"的判断需要业务语境的校准（不同客群基准不同）

### 容易混淆的邻近方法论

- 不是"OKR"——OKR 是目标管理，四层指标是经营健康度测量
- 不是"数据埋点"——埋点是数据采集，指标体系是选什么看
