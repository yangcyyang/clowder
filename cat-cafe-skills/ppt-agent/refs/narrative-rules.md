# 叙事规划规则

## 三种叙事模型

### 1. minto-pyramid（金字塔原理）

**适用场景**：受众需要先认同问题再接受方案时——咨询提案、解决方案推介、方法论分享。

**叙事阶段**：

| 阶段 | 英文 | 每阶段的核心任务 |
|------|------|-----------------|
| 1 | Situation | 界定问题与主结论 |
| 2 | Complication | 拆解关键论点 |
| 3 | Resolution | 提供证据支撑 |
| 4 | Proof | 用案例/数据验证 |
| 5 | Action | 收束到行动建议 |

### 2. duarte-sparkline（火花线）

**适用场景**：需要展示变革愿景、打动人心时——新品发布、变革推动、愿景宣讲。

**叙事阶段**：

| 阶段 | 英文 | 每阶段的核心任务 |
|------|------|-----------------|
| 1 | Current State | 呈现当前状态 |
| 2 | Future State | 展示理想未来 |
| 3 | Tension | 放大现状与未来的张力 |
| 4 | Proof | 证明转变路径可信 |
| 5 | Call to Action | 推动行动选择 |

### 3. 5w1h-chain（决策链）

**适用场景**：受众需要逐步回答决策链问题时——高管汇报、董事会决策、经营复盘。

**叙事阶段**：

| 阶段 | 英文 | 每阶段的核心任务 |
|------|------|-----------------|
| 1 | Why | 为什么现在要关注 |
| 2 | What | 到底要判断什么 |
| 3 | How | 如何落地推进 |
| 4 | Who | 谁受影响或负责 |
| 5 | When | 节奏与里程碑 |
| 6 | Decision | 形成决策闭环 |

## 选择原则

**不要用关键词匹配。** 理解以下三个维度后做判断：

1. **受众的决策模式**：
   - 需要逻辑说服 → minto-pyramid
   - 需要情感打动 → duarte-sparkline
   - 需要逐项回答 → 5w1h-chain

2. **场景的沟通目的**：
   - 提案/方案推荐 → minto-pyramid
   - 发布/变革/愿景 → duarte-sparkline
   - 汇报/复盘/决策 → 5w1h-chain

3. **内容的论证结构**：
   - 先结论后论据 → minto-pyramid
   - 先现状后愿景 → duarte-sparkline
   - 先问题后答案 → 5w1h-chain

**冲突处理**：多个模型都可用时，优先选受众决策模式匹配的那个。

## 故事主线（spine）

一句话概括整份 PPT 的叙事弧线。原则：

- 包含受众（给谁看）
- 包含起点（从哪里开始讲）
- 包含终点（讲到哪里结束）
- 包含价值（看完后获得什么）

## 章节标注

为每个章节标注：

| 字段 | 说明 |
|------|------|
| title | 章节标题 |
| purpose | 这个章节在叙事中的角色（从模型的阶段任务中选） |
| keyJudgement | 这个章节要让受众得出的关键判断（一句话） |
| evidenceNeeds | 支撑这个判断需要什么类型的证据 |
| stage | 对应叙事模型的哪个阶段 |

## 证据需求推理

根据章节内容推理需要什么证据：

| 证据类型 | 何时需要 |
|---------|---------|
| 量化指标 | 章节涉及效果、增长、转化、ROI |
| 客户案例 | 章节涉及落地实践、标杆客户 |
| 架构材料 | 章节涉及技术方案、系统设计 |
| 对比维度 | 章节涉及竞品、方案比较 |
| 合规证明 | 章节涉及安全、隐私、认证 |
| 实施计划 | 章节涉及路线图、里程碑 |

无明确匹配时，默认需要"事实证据"和"受众相关材料"。

## 输出格式

输出为 `narrative_plan.json`，schema：

```json
{
  "meta": { "title", "archetype", "audience", "scenario", "viewMode" },
  "spine": "一句话故事主线",
  "narrativeModel": "minto-pyramid | duarte-sparkline | 5w1h-chain",
  "chapters": [
    {
      "index": 1,
      "title": "章节标题",
      "purpose": "叙事角色",
      "keyJudgement": "关键判断",
      "evidenceNeeds": ["证据类型"],
      "stage": "叙事阶段"
    }
  ],
  "bridge": [
    { "fromChapter": 1, "toChapter": 2, "text": "过渡语" }
  ]
}
```
