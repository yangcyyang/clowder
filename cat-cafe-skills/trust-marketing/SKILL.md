# 信任营销与口碑传播

## R — 原文 (Reading)

> "企业级客户找到你的方式，不是刷到你的广告，而是：遇到难题，搜索、打听，发现某家公司对这个问题有过极其专业的公开论述，然后得出结论——『他们懂，找他们』。内容在这里扮演的角色，是客户决策链最前端的『资格预审』。"
>
> — 范冰《前线部署工程师》3.5

---

## I — 方法论骨架 (Interpretation)

FDE 获客逻辑决定内容营销不追求流量，追求"专业信任的预售"。四大模块：

1. **技术内容营销三军规**：写"战壕视角"不写"展台视角"（自曝家丑的文章成了 Palantir 模式最好的布道）/ 方法论开源制造"被引用的资格"（从供应商变成出题人）/ 让客户内部支持者成为内容里的英雄（给支持者舞台=给下一个客户递"成为他"的邀请函）
2. **借势三动作**（风口期）：定义议题（独家一手认知是议题定义权货币——打法手册/失败复盘/价值数据）/ 绑定行业议程（翻译成"董事会语言"："让你在下次董事会上拿出可量化 AI 成绩单"）/ 在风口期建立资产而不是消耗风口（案例+话语权+可复制交付体系）
3. **传播三圈层**：从业者社区（先行的布道者最后成为概念代名词）/ 客户的行业社区（被邀请演讲的客户支持者是最好的门票）/ 生态伙伴网络（让伙伴赢，帮别人成功的人被整个网络记住）。飞轮：交付创造故事→故事传播→带来新机会→新故事
4. **产品内置裂变因子**：可见性设计（输出物携带"出身"）/ 协作式准入（跨角色协作自然介绍系统）/ 自助化探索层（沙盒里长出的用法最有生命力）/ 跨边界价值证据（季度价值报告流向高管层）

核心原则：想让别人帮你传播，先得让人家实实在在用出了价值。企业市场没有病毒式传播，只有"口碑的链式反应"——慢，但每一步都坚实。

## A1 — 书中的应用 (Past Application)

### 案例1: Barry 的自曝家丑文章
- **问题**: 怎么写内容最有穿透力？
- **方法论的使用**: 写展台上看不到的东西——重复造轮子的浪费、负利润率试点、累垮的工程师
- **结论**: 战壕里的真话自带穿透力，读者能分辨谁在讲营销话术谁在讲现实
- **结果**: 成为 Palantir 模式最好的布道文

### 案例2: a16z 定义议题
- **问题**: 怎么收割行业注意力？
- **方法论的使用**: 一篇行业雄文为整个赛道定调
- **结论**: 风口注意力是公共资源，谁的内容定义议题谁收割
- **结果**: 成了 FDE 赛道绕不开的知识源头

### 案例3: J.D. Power 变成布道者
- **问题**: 口碑怎么跨行业传播？
- **方法论的使用**: 客户参加完训练营后开始为自己的客户办训练营
- **结论**: 从"感谢你"升级为"以用你为荣"；客户的客户是最深的护城河
- **结果**: Palantir 获客成本趋近于零

## E — 可执行步骤 (Execution)

1. **写战壕视角内容**
   - 完成标准：内容包含问题多难/我们怎么趟过去，而非产品多强；可含一个"自曝家丑"主题
   - 判停条件：内容全是展台视角 → 重写
   - 备注：方法论开源——"我们怎么做发现/验证/交付"

2. **把案例写成"英雄叙事"**
   - 完成标准：主角是客户方有远见的管理者（具体数字+具体人+具体反差），你的团队是"帮助他成功的伙伴"
   - 判停条件：案例主角是自己的产品 → 重写
   - 备注：给支持者舞台=递邀请函给下一个同类角色

3. **借势：定义议题 + 绑定议程**
   - 完成标准：识别风口气流（报告/巨头动作/岗位增长），用一手认知定义议题；把方案翻译成"董事会语言"
   - 判停条件：只蹭热度没有独家认知 → 无效借势

4. **经营三圈层**
   - 完成标准：从业者社区贡献内容 / 客户行业社区让支持者被邀请演讲 / 生态伙伴"赢"在合作中
   - 判停条件：只在自有渠道发声 → 圈层没打通

5. **预埋产品裂变因子**
   - 完成标准：输出物携带出身（页脚"由 X 生成"）+ 协作式准入 + 沙盒探索层 + 季度价值报告流向高管
   - 判停条件：为传播而传播的设计 → 企业场景会被识别为"厂商小动作"而遭反感

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 流量驱动的消费级营销（转化逻辑不同）
- 付费广告投放（预算驱动，非信任预售）

### 书中警告的失败模式

- 展台视角内容：读者能分辨营销话术 vs 战壕真相
- 为传播而传播：企业场景识别"厂商小动作"而反感
- 借势只消耗不建设：风口停了，什么都没留下
- 案例不署名客户方：主角是自己，失去"成为他"的邀请函效应

### 作者的盲点 / 时代局限

- "方法论开源"有被竞争对手模仿的风险（书中论证：定义权收益大于教会同行的损失，但小团队可能承受不了）
- 2026 年 AI 内容泛滥，战壕视角/独家一手认知的稀缺性上升，但也更难被识别

### 容易混淆的邻近方法论

- 不是"品牌广告"——信任营销是资格预审，广告是曝光
- 不是"SEO 流量"——不追求流量，追求专业信任的预售
