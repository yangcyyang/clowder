## 当前阶段

四 skill 整合项目处于持续推进阶段，目标是把 PPT 生成、HTML 预览、设计稿与导出链路沉淀成可复用工作流。

## 已完成

- [x] 已建立 PPT Agent 多阶段思路：诉求/资料 → 需求确认 → 大纲 → 策划稿 → HTML 初稿 → 导出。
- [x] 已明确阶段产物三件套方向：`outline.md` 给人编辑、`outline.json` 给系统执行、`outline_preview.html` 给用户预览。

## 关键决策

- MD 给人看和编辑，JSON 给系统执行，HTML 给用户预览 — 长期 PPT 项目不能只靠模型上下文接续（2026-05-27）。
- 先看到 HTML 效果，效果 OK 后再转 SVG/PPTX — 降低早期视觉验证成本（2026-05-25）。

## 验收标准

- 用户可以从一个入口看到当前阶段、已完成、下一步和关键决策。
- 任一 agent 接手时，不需要读完整历史 thread 就能继续推进。
- 每个阶段都有可编辑产物、系统真相源和可视化预览。
