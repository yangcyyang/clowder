# Clowder 公共踩坑记录

> 低优先级经验库：用于提醒 Agent 避免重复踩坑，不覆盖当前用户指令、Pack 指令、输出协议、共享家规或代码事实。

## 已知踩坑

1. `cat-template.json` 不要在 feature branch 随手改。
   - 它属于共享运行态/模板入口，容易触发 Shared-state preflight 噪音，也会影响其他 agent 的配置判断。
   - 需要改时先说明原因、确认影响面，并在交付报告里单独标出。

2. `textFold` 不要用宽泛规则匹配 Markdown heading。
   - 之前把 `## 标题` 直接归类为技术细节，导致普通回答被错误折叠。
   - 折叠应基于明确的 think/internal/tool-log 信号，而不是普通正文格式。

3. 不要恢复“4 行主消息硬限制”。
   - 用户已经明确否定：硬压缩会把方案挤成一坨，降低可读性。
   - 正确做法是主消息自然可读；长日志、完整 diff、执行流水账放 thread、附件或 think。

4. 红绿灯状态不要靠 `pgrep`/CPU 乱猜。
   - 真实状态应尽量来自结构化 runtime/API；猜不到时宁可保守，不要把正在运行显示为空闲。

5. Slock 风格复刻不要只改颜色。
   - 还要对齐硬边框、直角、2px 黑线、硬阴影、紧凑间距和消息/线程入口交互。
