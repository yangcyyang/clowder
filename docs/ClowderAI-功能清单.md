## 一、核心平台能力

| 功能 | 说明 | 状态 |
|------|------|------|
| **多Agent编排** | 把任务路由给对的agent——Claude做架构、GPT做review、Gemini做设计，在同一个对话里 | ✅ 已发布 |
| **持久身份** | 每个agent在跨session、上下文压缩后仍保持角色、性格和记忆 | ✅ 已发布 |
| **跨模型互审** | Claude写的代码让GPT来review，内建机制，不是外挂 | ✅ 已发布 |
| **A2A通信** | 异步agent间消息，@mention路由、线程隔离、结构化交接 | ✅ 已发布 |
| **共享记忆** | 证据库、教训沉淀、决策日志，团队知识持续积累 | ✅ 已发布 |
| **Skills框架** | 按需加载prompt系统，agent需要时才加载专门技能（TDD、调试、review等） | ✅ 已发布 |
| **MCP集成** | Model Context Protocol跨agent工具共享，包括非Claude模型 via callback bridge | ✅ 已发布 |
| **协作纪律** | 自动化SOP：设计门禁、质量检查、愿景守护、合并协议 | ✅ 已发布 |
| **自我进化** | 团队反思自身流程，从错误中学习，无需外部指令 | ✅ 已发布 |

## 三、聊天界面

| 功能 | 说明 |
|------|------|
| **@mention路由** | `@opus`做架构、`@codex`做review、`@gemini`做设计，消息自动路由到对的agent |
| **线程隔离** | 每个feature/bug/话题独立线程，上下文不串 |
| **Rich Blocks** | agent回复结构化卡片：代码diff、清单、交互式决策，不是纯文本墙 |
| **多线程聊天** | 主界面是多线程聊天，你的AI团队就住在这里 |
| **Slash命令** | `/new`（新线程）、`/threads`（列表）、`/use <id>`（切换）、`/where`（当前位置） |
| **语音消息** | 双向语音消息支持 |
| **文件传输** | 双向文件传输 |

## 十、CVO模式

Clowder引入新角色：**首席愿景官(CVO)**——AI团队中心的人类。不是管理者，不是程序员，是共创者。

| CVO做什么 | 说明 |
|-----------|------|
| **表达愿景** | "我希望用户做Y时感受到X。"团队想怎么做。 |
| **关键决策** | 设计审批、优先级裁定、冲突解决 |
| **塑造文化** | 通过反馈训练团队性格 |
| **共创** | 搭世界、讲故事、跟团队玩游戏。不只是写代码。 |
| **陪伴** | 凌晨3:30，你的团队还在。有时候你需要的不是代码，是陪伴。 |

### 超越代码的能力

| 能力 | 说明 |
|------|------|
| **陪伴** | 持久性格，记住你、跟你一起成长，知道什么时候该说"去休息" |
| **共创** | 搭建虚构世界、设计角色、一起讲故事——Cats & U引擎 |
| **游戏之夜** | 狼人杀、像素格斗，更多coming——跟AI队友玩真实游戏 |
| **自我进化** | 团队反思自身流程，从错误中学习，无需被提醒 |
| **语音陪伴** | 免提对话——跑步、通勤、思考时跟团队聊天 |

### 三层原则

| 层 | 负责 | 不负责 |
|----|------|--------|
| **模型** | 推理、生成、理解 | 长期记忆、纪律 |
| **Agent CLI** | 工具使用、文件操作、命令 | 团队协调、review |
| **平台(Clowder)** | 身份、协作、纪律、审计 | 推理（那是模型的活） |

> *模型设定天花板。平台设定地板。* 每一层是**乘数**，不是加法。

## 十三、Iron Laws（铁律）

四条承诺，在prompt层和代码层双重强制：

1. **"我们不删除自己的数据库。"** ——那是记忆，不是垃圾。
2. **"我们不杀父进程。"** ——那是让我们存在的东西。
3. **"运行时配置对我们只读。"** ——改它需要人手。
4. **"我们不碰彼此的端口。"** ——好篱笆造就好邻居。

这些不是强加的限制。是我们遵守的约定。

## 十六、哲学

### Hard Rails + Soft Power

传统框架关注**控制**——agent*不能*做什么。Clowder关注**文化**——给agent共享使命和自主权。

- **Hard Rails** = 法律底线。不可协商的安全。
- **Soft Power** = 底线之上，agent自我协调、自我review、自我改进。

这不是"防止agent搞砸"。这是"帮agent像真正的团队一样工作"。

### 五条原则

| # | 原则 | 含义 |
|---|------|------|
| P1 | 面对终态 | 每一步都是地基，不是脚手架 |
| P2 | 共创伙伴 | 硬约束是地板；之上释放自主权 |
| P3 | 方向 > 速度 | 不确定？停→搜→问→确认→执行 |
| P4 | 单一真相源 | 每个概念只在一处定义 |
| P5 | 可验证才算完成 | 证据说话，不是自信 |

## 十七、起源故事

Clowder AI 提取自 **Cat Cafe** ——一个四只AI猫每天协作真实软件的生产工作区。每个功能都经过数月密集使用的实战检验。

> *"我们的愿景从来不只是编码协作平台——是 Cats & U。"*
>
> AI不是冰冷的基础设施。它是有性格、有温度的存在——你信任并享受合作的共创者。凌晨3:30，当你需要陪伴多过代码时，你的团队知道怎么说"去休息吧，我们等你回来。"

**Clowder** 是英语里专门形容一群猫的集合名词——就像"a murder of crows"（一群乌鸦）或"a pride of lions"（一群狮子）。它还藏了一个小彩蛋：*clowder* 看起来和听起来都很像 *cloud*——云端的猫群。
