# Slock-like WebUI 视觉清单

> 用于验收 clowder-ai 改造后的视觉效果
> 基于 `slock-like-webui-spec.md` 和 `slock-like-webui-mock.html`

---

## 1. 色板规范

### 1.1 主色调

| 用途 | 色值 | 说明 |
|------|------|------|
| 背景主色 | `#f7f4ef` | 温暖米白底 |
| 侧边栏背景 | `#ebe3d8` | 稍深的米色 |
| 面板背景 | `#f1e9df` | 暖灰 |
| 卡片/纸张 | `#fffdf9` | 纯白偏暖 |
| 分割线 | `#e2d5ca` | 柔和暖灰 |
| 强分割线 | `#d2c0b2` | 稍深 |

### 1.2 文字色

| 用途 | 色值 | 说明 |
|------|------|------|
| 主文字 | `#241f1b` | 深棕黑 |
| 次要文字 | `#7a6f66` | 暖灰 |
| 弱文字 | `#a1958b` | 浅灰 |

### 1.3 强调色

| 用途 | 色值 | 说明 |
|------|------|------|
| 主强调 | `#d97757` | 暖橙 |
| 强调浅底 | `#f3dfd4` | 浅橙 |
| 链接/信息 | `#4f7ecf` | 蓝色 |
| 成功/在线 | `#2f9e63` | 绿色 |

### 1.4 验收标准

- [ ] 整体色调温暖、不刺眼
- [ ] 暗色模式有对应变量（如有）
- [ ] 强调色用于交互元素（按钮、链接、在线状态）
- [ ] 文字对比度符合 WCAG AA 标准

## 2. 圆角规范

| 元素 | 圆角 | 说明 |
|------|------|------|
| 导航按钮 | `12px` | Activity Rail 按钮 |
| 卡片 | `10px` | 消息卡片、面板 |
| 输入框 | `10px` | 消息输入框 |
| 标签/Badge | `10px` | 状态标签 |
| 头像 | `50%` | 圆形头像 |
| 模态框 | `14px` | 弹窗 |

### 验收标准

- [ ] 圆角统一，不混用不同值
- [ ] 阴影柔和（`0 20px 60px rgba(42, 35, 28, 0.08)`）
- [ ] 悬浮状态有轻微上移或阴影变化

---

## 3. 间距规范

| 场景 | 间距 | 说明 |
|------|------|------|
| 页面内边距 | `14px` | 面板内边距 |
| 卡片间距 | `8px` | 消息卡片之间 |
| 元素间距 | `6px` | 同一行元素之间 |
| 区域间距 | `16px` | 不同区域之间 |
| 大区域间距 | `24px` | 页面区块之间 |

### 验收标准

- [ ] 间距统一，不混用
- [ ] 移动端间距适当缩小
- [ ] 内容密度适中，不过于稀疏或拥挤

---

## 4. 字体规范

| 用途 | 字体 | 大小 | 行高 |
|------|------|------|------|
| 正文 | 系统字体栈 | `14px` | `1.5` |
| 标题 | 系统字体栈 | `16px` | `1.3` |
| 小字 | 系统字体栈 | `12px` | `1.4` |
| 代码 | 等宽字体 | `13px` | `1.5` |

### 字体栈

```css
font-family: ui-sans-serif, -apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", sans-serif;
```

### 验收标准

- [ ] 中文显示清晰
- [ ] 代码块使用等宽字体
- [ ] 行高舒适，不拥挤

## 5. 消息样式

### 5.1 用户消息

- 背景：`var(--paper)` 或略深
- 对齐：右对齐
- 头像：右侧圆形头像
- 时间：消息下方，小字灰色

### 5.2 Agent 消息

- 背景：`var(--soft)` 浅灰
- 对齐：左对齐
- 头像：左侧圆形头像（可用猫猫头像或通用图标）
- 名称：Agent 名称 + 在线状态
- 时间：消息下方，小字灰色

### 5.3 系统消息

- 背景：透明或极浅
- 对齐：居中
- 字体：小字灰色
- 用途：任务状态变更、Agent 加入/离开

### 5.4 Task 消息

- 背景：带左侧色条（蓝色/绿色/橙色）
- 状态：显示 task 状态（todo/in_progress/done）
- 指派：显示指派给哪个 Agent

### 验收标准

- [ ] 消息类型视觉区分明显
- [ ] Agent 消息有明确的"非用户"标识
- [ ] 系统消息不抢视觉焦点
- [ ] Task 状态一目了然

---

## 6. 侧边栏样式

### 6.1 Activity Rail（最左侧）

- 宽度：`56px`
- 背景：`var(--rail)`
- 内容：Logo + 导航按钮
- 按钮：`40px × 40px`，圆角 `12px`
- 激活态：白色背景 + 强调色图标

### 6.2 Space List（左侧主栏）

- 宽度：`282px`
- 背景：`var(--panel)`
- 内容：
  - 搜索框
  - 项目空间分组
  - 最近对话
  - Agent DM
  - Pinned
- 分组标题：大写、灰色、小字
- 选中态：`var(--paper)` 背景 + 左侧色条

### 验收标准

- [ ] 侧边栏不抢主内容区注意力
- [ ] 分组清晰，层次分明
- [ ] 选中态明显
- [ ] 搜索框易发现

---

## 7. 右侧 Context Panel

### 7.1 布局

- 宽度：`336px`
- 背景：`var(--panel)`
- Tab：Tasks / Agents / Evidence / Files
- 可折叠/隐藏

### 7.2 内容密度

- 任务卡片：紧凑，显示状态 + 指派 + 标题
- Agent 状态：头像 + 名称 + 状态（在线/执行中/失败）
- 证据列表：标题 + 来源 + 时间
- 文件树：目录结构 + 代码高亮

### 验收标准

- [ ] 不遮挡主消息流
- [ ] Tab 切换流畅
- [ ] 内容密度适中
- [ ] 可折叠/隐藏

---

## 8. 输入框样式

### 8.1 布局

- 位置：底部固定
- 高度：自适应（最小 `44px`，最大 `200px`）
- 圆角：`10px`
- 边框：`var(--line)` 默认，`var(--accent)` 聚焦

### 8.2 功能区

- 左侧：附件按钮、表情按钮（可选）
- 右侧：发送按钮
- 中间：输入区域

### 8.3 状态

- 默认：灰色边框
- 聚焦：强调色边框
- 发送中：按钮变为加载态
- 排队中：显示"排队中"提示

### 验收标准

- [ ] 输入框醒目，易发现
- [ ] 发送按钮明确
- [ ] 多行输入自动扩展
- [ ] 状态反馈清晰

---

## 9. 响应式规范

| 断点 | 布局变化 |
|------|----------|
| `> 1200px` | 四栏完整显示 |
| `800-1200px` | 隐藏右侧 Panel |
| `< 800px` | 隐藏侧边栏，只显示消息流 |

### 验收标准

- [ ] 移动端可正常阅读消息
- [ ] 侧边栏可收起
- [ ] 输入框始终可见

---

## 10. 禁改边界

以下组件/模块**不在本次改造范围内**：

- A2A 路由逻辑
- Redis 存储结构
- Evidence Store
- Invocation Queue
- CLI Adapter
- 猫猫品种系统（底层保留，UI 可弱化）

### 验收标准

- [ ] 改造后 A2A 调用正常
- [ ] Redis 数据无变化
- [ ] Evidence Store 功能正常
- [ ] Invocation 状态显示正确

---

## 11. 整体验收清单

### 视觉一致性
- [ ] 色板统一
- [ ] 圆角统一
- [ ] 间距统一
- [ ] 字体统一

### 功能完整性
- [ ] 消息发送/接收正常
- [ ] Thread 切换正常
- [ ] Agent @mention 正常
- [ ] Task 状态显示正常
- [ ] 右侧 Panel 可用

### 用户体验
- [ ] 第一眼是"协作消息平台"，不是"猫猫游戏工作台"
- [ ] 用户知道当前是在对谁说话
- [ ] 用户知道 Agent 是"排队中/执行中/已完成/失败"
- [ ] 用户能理解消息可以进入 thread 继续讨论
